## 3. 关键工程决策（已锁定，勿再改动）

1. **坐标系**：Y 轴向上，1 单位 = 1 米，资产正面朝向 **+Z**（glTF 惯例），锚点 = 脚底中心 (0,0,0)。
2. **命名**：GLB 文件名前缀 = category 枚举（`char_/animal_/plant_/fish_/building_/prop_/terrain_/col_`），LOD 后缀小写 `_lod<N>`；manifest 内 assetId = `<category>_<name>`，并带 `designId`（如 `ANI-001`）桥接设计清单。
3. **碰撞体策略**：运行时按类别规则生成（主 B）+ 占位对象 `_collider_*`（辅 C）；**渲染 mesh 永不直接进物理**，一律简化代理（box > sphere > capsule > cylinder > convex_hull > trimesh > heightfield）。
4. **刚体类型映射**：地形/建筑/装饰=fixed；NPC/动物/平台=kinematic（或 dynamic 圈养）；道具/果实=dynamic + 睡眠；交互判定=sensor。
5. **物理步进**：固定 1/60s + 累计器 + 渲染插值；禁止在 rAF 里直接 step。
6. **渲染支持**：gradientMap Toon（manifest `materialMode:"toon"` 全局注入，水面/金属可 `"standard"` 共存）、InstancedMesh（单批 ≤2048）、KTX2 压缩均已确认支持。
7. **骨骼复用**：仅 3 套骨架覆盖 10 种动物（4 足大型 / 2 足小型 / 4 足小型），鱼用程序化摆动不建骨骼。
8. **性能预算基准（T2 中端手机）**：同屏对象 ≤300、动态刚体 ≤50、DrawCalls ≤150、tris ≤300k、纹理 VRAM ≤128MB。

## 4. 开工顺序建议（里程碑 M1-P0 首批）

> 依据 asset-manifest.md 第 8 章生产顺序：先环境地基 → 再闭环功能 → 后丰富品种。

```
M1 第 1 周（P0 首批 25 个）：
  ① 地形/水面（ENV-001/004）→ ② 工具（锄/壶/镰/竿）→ ③ 作物+耕地（小麦/胡萝卜/地块）
  → ④ 动物+畜舍（鸡/牛 + 鸡舍/牛棚/围栏）→ ⑤ 鱼（鲤鱼/鲈鱼 + 鱼塘）→ ⑥ 闭环件（农舍/出货箱/饲料/篮/蛋/奶）

M2 第 2 周起（P1 第二波 25 个）：羊/猪/鸭、6 作物、3 果树、3 新鱼、谷仓/水井、斧头、草丛/花丛/路径
M3 后续（P2 扩展 22 个）：温室/马厩、马/兔/羊驼/猫/狗、高级作物/花、肥料/蜂蜜/金币、山丘
```

**并行建议**：地形+工具最先开工（无动画依赖）；动物骨骼与动画最早启动（CC0 采购/重定向耗时最长）；**先验证牛动画管线再批量**（风险 #1）。

## 6. 已知风险与缓解

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | CC0 卡通四足动画稀缺，重定向可能失真 | M1 先做牛动画管线验证，再批量；动画走 Mixamo 类卡通动作重定向 |
| 2 | 同屏动态刚体超限（动物+掉落物） | 工程预算 ≤50（T2），掉落物启用睡眠 + 60s 自动清理 |
| 3 | rapier3d-compat 版本 API 变化 | 锁 minor + 物理封装单点 + CI 编译检查 |
| 4 | KTX2 安卓兼容性 | 运行时检测 + JPEG/PNG fallback |
| 5 | 多人同步未实现 | 逻辑层与传输层解耦，预留 WebSocket 通道设计 |
