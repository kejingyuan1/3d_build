## 0. 阅读指引

本文档是**整个资产生产的第一份输入**，回答三个问题：

1. **做什么**：全量 3D 资产清单（动物 / 植物 / 鱼类 / 建筑 / 道具 / 环境）。
2. **为什么**：核心循环 → 三大玩法支柱 → 支柱到资产的映射，作为取舍依据。
3. **先做哪些**：P0（首周可玩闭环）/ P1（第二波丰富）/ P2（长线扩展）三级优先级 + 生产顺序建议。

**对工程（engineering-lead）特别说明**：资产必须支持物理碰撞（捡拾、投喂、堆叠、角色碰撞等玩法需求），每个条目已标注碰撞体类型与用途；第 6 章给出碰撞体配置总则。
**对美术（art-director）特别说明**：每个条目已标注动画需求与建议生产途径（Procedural 程序化 / CC0 资产库 / Hybrid 双轨）；第 7 章给出动画需求总则。面数与 LOD 为建议参考，最终以美术圣经与工程性能预算为准。

## 1. 游戏核心循环与玩法支柱

### 1.1 一句话概念

> 一款卡通风格、3D 第三人称的农场牧场经营网页游戏：玩家经营一片农场，通过**种植作物、养殖动物、垂钓采集**获得产出，交易赚钱并持续扩建自己的农场。

### 1.2 玩家每日循环（Day Loop）

```
起床 → 收取产物（蛋/奶/成熟作物）
     → 投喂动物（饲料 → 食槽 → 动物饱食/好感上升）
     → 白天：耕地 → 播种 → 浇水 →（等待生长）
     → 可选活动：钓鱼、采集（草→饲料、树→木材、石头）
     → 交易：产物放入出货箱 → 获得金币
     → 扩展：金币解锁新作物/动物/建筑/区域
     → 睡觉：保存进度、推进游戏内日期
```

核心节奏：**产出 → 出售 → 扩展 → 更多产出**。每个循环产出一次正反馈（金币入账），并以新解锁内容延长新鲜感。

### 1.3 三大玩法支柱（Design Pillars）

支柱是资产取舍的"北极星"——任何资产增删都问一句：它支撑哪个支柱？不支撑任何支柱的资产不进 P0/P1。

**支柱 1：种植与收获（Grow & Harvest）**
- 核心动词：锄地、播种、浇水、等待、收获、出售
- 玩家心理：规划感 + 延迟满足（种下 → 期待 → 收获）
- P0 依赖资产：小麦、胡萝卜、耕地地块、锄头、水壶、镰刀、篮子、出货箱

**支柱 2：畜牧养殖（Raise & Care）**
- 核心动词：建造畜舍、投喂、抚摸、收集产物、陪伴成长
- 玩家心理：照料感 + 情感联结（耕耘者/社交者玩家类型）
- P0 依赖资产：鸡、牛、鸡舍、牛棚、围栏、饲料、鸡蛋、牛奶

**支柱 3：垂钓采集与探索（Fish & Forage）**
- 核心动词：抛竿、等待、收线、采集、探索水域
- 玩家心理：随机性惊喜 + 收集图鉴（收藏家玩家类型）
- P0 依赖资产：鲤鱼、鲈鱼、鱼塘/水面、鱼竿

**Meta 循环：交易与扩展（Sell & Expand）**——三大支柱的共同经济出口，驱动长期留存（金钱 → 扩建 → 解锁新玩法）。

## 2. 优先级逻辑

### 2.1 分级定义

| 级别 | 含义 | 目标 |
|---|---|---|
| **P0 首批** | 支撑"种植 + 养殖 + 钓鱼"最小可玩闭环，**第一周内可完整玩通** | 玩家 Day 1-7 内跑通：种小麦 → 收小麦 → 喂牛 → 挤奶 → 钓鱼 → 出货 → 扩建 |
| **P1 第二波** | 品种多样性与系统深度，第二周起上线 | 更多作物/动物/鱼、存储（谷仓）、工具扩展（斧头砍树）、建筑扩展（水井） |
| **P2 扩展** | 长线内容，后续迭代 | 温室、骑乘、宠物系统、高级产物（羊毛/蜂蜜/肥料） |

### 2.2 P0 选择逻辑（25 个，≤ 25 上限）

- **每支柱只保留"闭环必须"资产**，一个不允许多，一个不能少：
  - 种植闭环必须：1 地块 + 2 作物（小麦快收、胡萝卜慢收形成节奏）+ 3 工具 + 1 出货口
  - 养殖闭环必须：2 动物（鸡产蛋快、牛产奶标志性强）+ 对应畜舍 + 围栏 + 饲料 + 2 产物
  - 钓鱼闭环必须：1 水域 + 2 鱼 + 鱼竿
  - 环境必须：地形 + 基础障碍（树/石）+ 水面
- **动物为何先做鸡 + 牛**：鸡是养殖最快正反馈（2-3 天内产蛋），牛是标志性产出（牛奶），两者构成"快慢节奏"；羊、猪虽有特色但非首周闭环必须，让位 P1。
- **果树为何放 P1**：生长周期长（多阶段、数日成熟），P0 内无法体现闭环收益，优先级让位于能即时出货的作物。
- **数量核验**：P0 恰好 25 个（见第 5 章统计），不突破上限，控制首批生产规模。

> - **ID**：全局唯一编号，供美术/工程/后续 GDD 引用。
> - **玩法用途**：该资产在玩法中的角色，括号内注明主要交互类型（种植/收获/投喂/捡拾/堆叠/碰撞/交互）。

## 4. 关键资产规格明细（P0 全量 + P1 重点）

> 本节给工程与美术可落地的规格：生产途径、动画清单、碰撞体详细配置、变体与 LOD 建议。P0 全部 25 个给出详细规格；P1 仅对碰撞/动画有特殊要求的资产补充说明。

### 4.1 P0 详细规格（25 个）

#### 动物

**ANI-001 牛（Cow）**
- 生产途径：CC0 模型库 + 骨骼重定向（Stylized 低模）；建议 2-3 配色变体（黑白荷斯坦/棕牛）。
- 动画清单：idle（站立呼吸）、walk（四足步态循环）、eat（低头咀嚼，投喂后触发）、hurt（受击/被撞反应）。可选 sleep。
- 碰撞体：**Dyn 胶囊体**（半径≈0.6m，高≈1.6m，质心低置防翻倒）。用途：与围栏、建筑碰撞形成圈养；与玩家碰撞产生推动；投喂时以自身 Sensor（半径≈2.5m 的检测圈）检测地上饲料。
- LOD：LOD0≈4k tris，LOD1≈2k；可共享 4 足骨骼与羊/猪复用。

**ANI-002 鸡（Chicken）**
- 生产途径：CC0 模型库 + 骨骼；建议 2 色变体（白/棕）。
- 动画清单：idle、walk（小碎步）、eat（啄食）、peck（啄地）、hurt。可选 sleep（进舍后蹲伏）。
- 碰撞体：**Dyn 胶囊体**（半径≈0.2m，高≈0.5m）。用途：圈养阻挡、投喂检测（Sensor 半径≈1.2m）；体型小，可进入鸡舍产蛋点。
- LOD：LOD0≈1.5k tris；可与鸭共享骨骼骨架。

#### 植物

**PLA-001 小麦 / PLA-002 胡萝卜（Wheat / Carrot）**
- 生产途径：Procedural（低模茎叶 + 贴图），每作物 1 套资源含 3 阶段变体（种子粒 → 幼苗 → 成熟）。
- 动画：成熟期顶点轻微摆动（风），由 Shader/简单脚本实现，不需骨骼动画。
- 碰撞体：**幼苗期 None 或极矮 Sensor**（避免玩家走路被挡）；**成熟期 Static 小凸包（底部 0.1m 高底座）+ 头顶 Sensor 收获区**。用途：收获交互判定（靠近按 E 收割）；作物本体不阻挡玩家穿行种植区。
- LOD：LOD0≈300 tris/株；批量种植时建议实例化（InstancedMesh）合并绘制。

**PLA-023 耕地地块（Tilled Soil）**
- 生产途径：Procedural，单块可拼接（1m×1m），用贴图法线表现犁沟。
- 动画：无（浇水后贴图变湿色可选）。
- 碰撞体：**Static 薄盒（0.05m 高）**，贴合地形表面。用途：行走不卡脚、承载作物、锄头命中区域判定。
- 备注：与地形块 ENV-001 对齐（同一网格尺寸），避免缝隙。

#### 鱼类

**FIS-001 鲤鱼 / FIS-002 鲈鱼（Carp / Bass）**
- 生产途径：Procedural（低模鱼体 + 贴图），可共享骨架做 6 种鱼变体。
- 动画：游动左右摆尾（程序化正弦摆动即可，无需骨骼）；上钩挣扎（抖动）。
- 碰撞体：**上钩时以鱼线末端挂点为 Sensor（无物理体）**；放入鱼塘养殖时 Dyn 小胶囊（半径≈0.15m）。用途：垂钓命中判定、养殖容器内碰撞。
- LOD：LOD0≈800 tris；池塘内建议限制同屏鱼数（≤20）。

#### 建筑

**BLD-001 农舍（Farmhouse）**
- 生产途径：CC0 木屋模型 + 配色调整（Stylized）。
- 动画：无（烟囱烟雾粒子可选）。
- 碰撞体：**Static 墙体盒体组合**；门洞留空不设碰撞；门口加 Sensor 进门交互（睡觉确认 UI）。
- LOD：LOD0≈8k tris（场景主角建筑，可稍高）。

**BLD-002 鸡舍 / BLD-003 牛棚（Coop / Barn）**
- 生产途径：CC0 小型畜舍模型；可与农舍共享建材贴图。
- 动画：无（门开合为 P1 可选）。
- 碰撞体：**Static 墙体盒体**；门洞 Sensor 进出；牛棚内设**挤奶交互点 Sensor**（玩家站定按 E 接奶）；鸡舍内设**产蛋点 Sensor**（鸡进入后定时产蛋）。
- LOD：LOD0≈5k tris。

**BLD-004 围栏（Fence）**
- 生产途径：Procedural，段件（直段/转角段/门段）可拼接；建议 1 直段 + 1 转角 + 1 门段共 3 变体。
- 动画：无。
- 碰撞体：**Static 细长盒（约 0.15m 宽、1.0m 高）**，按段拼接；门段开门时切换 Kin（移开）或 Sensor。用途：物理阻挡动物越界、玩家视觉边界。
- 备注：动物需配合 AI 避开（NavMesh/steering），不依赖纯物理推挤。

**BLD-005 鱼塘/池塘（Pond）**
- 生产途径：Hybrid——地形凹陷（Procedural）+ 水面 Shader（波纹）+ 岸边石块（CC0 复用 ENV-003）。
- 动画：水面 Shader 波纹；鱼影游动（可选贴花）。
- 碰撞体：**岸边 Static 凸包/盒体（可站立）**；**水面 Sensor（垂钓点判定 + 抛竿命中判定）**；水体内 P0 不开放潜水，玩家不可走入（水面处设隐形 Static 薄面拦截）。
- LOD：水面单面片 + 岸边低模即可。

**BLD-010 出货箱（Shipping Box）**
- 生产途径：Procedural 木箱（与围栏/谷仓共享木材贴图）。
- 动画：无（盖子开合可选）。
- 碰撞体：**Static 盒体 + 交互 Sensor（半径≈1.5m）**。用途：靠近打开出售 UI；放入产物即时售出。

#### 道具

**ITM-001 锄头 / ITM-004 镰刀（Hoe / Scythe）**
- 生产途径：Procedural（木柄 + 金属头），手持比例放大（Stylized 惯例）。
- 动画：挂在玩家手部骨骼；挥动时播放玩家动作。
- 碰撞体：**手持时无物理碰撞**；挥动帧创建**临时 Sensor** 做命中检测（锄地/割草判定）。用途：锄地生成 PLA-023、收割 PLA 作物与 ENV-005 草丛。

**ITM-002 水壶（Watering Can）**
- 生产途径：Procedural。
- 动画：手持；浇水动作 + 水滴粒子（不建模水流实体）。
- 碰撞体：**手持无碰撞**；浇水判定用射线/Sensor 指向地块。用途：给作物浇水（地块湿度状态）。

**ITM-003 鱼竿（Fishing Rod）**
- 生产途径：Procedural（杆 + 线 + 浮漂）。
- 动画：玩家抛竿/收线动作；鱼线用 LineRenderer（非物理体）；浮漂上下浮动。
- 碰撞体：**手持无碰撞**；抛竿落点判定用 Sensor/射线；上钩后鱼挂线（Sensor 挂点）。用途：钓鱼状态机（抛竿 → 等待 → 咬钩 → 收线 → 获得鱼）。

**ITM-006 饲料/干草（Feed / Hay）**
- 生产途径：Procedural（干草捆，低模圆柱/盒）。
- 动画：无。
- 碰撞体：**Dyn 小盒体（约 0.4m 立方，可抛掷/落地/堆叠）**；放置或投掷到动物附近时，动物 Sensor 检测并触发 eat。用途：投喂玩法核心——支持"拿起→抛向动物→动物进食→饱食度上升"完整交互链。

**ITM-007 篮子（Basket）**
- 生产途径：Procedural 编织篮。
- 动画：手持摇摆。
- 碰撞体：手持无碰撞；作为掉落物时 Dyn 小盒。用途：拾取产物视觉容器（携带上限表现）。

**ITM-008 鸡蛋 / ITM-009 牛奶（Egg / Milk）**
- 生产途径：Procedural（蛋 = 椭球体；奶瓶 = 瓶体 + 牛奶材质）。
- 动画：无。
- 碰撞体：**Dyn 小球体/小盒体（可被玩家拾取、可堆叠、可放入出货箱/篮子）**。用途：产物拾取闭环——动物产 → 掉落 → 玩家捡起 → 携带 → 出售。这是"捡拾/堆叠"物理需求的核心用例。

#### 环境

**ENV-001 草地地形块（Grass Terrain Tile）**
- 生产途径：Procedural（高度场或平铺网格），贴图草色。
- 动画：无（可选草叶摇摆）。
- 碰撞体：**Static 高度场/贴合凸包**；与 PLA-023 耕地地块、ENV-007 路径同网格对齐。
- 备注：P0 用单一大地块 + 边缘装饰即可，不做多 Tile 拼接复杂度。

**ENV-002 基础树（Tree Base）**
- 生产途径：Procedural（树干圆柱 + 树冠球簇），可 2-3 变体（树形/大小）。
- 动画：树叶/树冠顶点摆动。
- 碰撞体：**树干 Static 圆柱（半径≈0.4m）**阻挡；树冠 None 或 Sensor（P1 砍树判定）。用途：P0 装饰 + 碰撞障碍；P1 可砍伐产木材。

**ENV-003 石头（Rock）**
- 生产途径：Procedural（低模凸包石，随机缩放），可 3 变体。
- 动画：无。
- 碰撞体：**Static 凸包**。用途：碰撞障碍 + 场景点缀；P2 可敲碎产石材（破碎为多个 Dyn 碎石）。

**ENV-004 水面（Water Surface）**
- 生产途径：Shader（半透明蓝 + 波纹法线动画）。
- 动画：Shader 波纹（非网格动画）。
- 碰撞体：**Static 薄面（可站立边缘）+ Sensor（垂钓判定）**。用途：钓鱼玩法判定区 + 视觉水体。

## 6. 碰撞体配置总则（供 engineering-lead）

> 基于 Rapier 物理（Three.js 集成）。以下为设计侧统一约定，工程实现细节以其技术文档为准。

1. **单位与坐标系**：1 游戏单位 = 1 米；Y 轴向上；碰撞体尺寸以米标注（见第 4 章）。
2. **类型映射**：
   - `Static` → Rapier `RigidBodyDesc::fixed`（地形、建筑、树、石、围栏）。
   - `Dyn` → Rapier `RigidBodyDesc::dynamic`（动物、可拾取掉落物、可抛掷饲料）。掉落物统一启用**睡眠**（休眠）以减少持续计算。
   - `Kin` → Rapier `RigidBodyDesc::kinematicPositionBased`（围栏门段开合等受控移动物）。
   - `Sensor` → 无碰撞响应的触发器，仅做**进入/退出回调**，用于交互判定（收获区、投喂检测、垂钓点、UI 交互区）。
3. **交互分层（Filter Group）**：至少分 5 层：`玩家`、`动物`、`掉落物`、`工具命中`、`交互Sensor`。掉落物只与地面/容器碰撞，不与动物互推；工具命中 Sensor 只检测目标层（作物/地块/草丛），避免误伤动物。
4. **捡拾/堆叠物理**（核心用例）：鸡蛋/牛奶/饲料等可拾取物用 Dyn + 小碰撞体；拾取时切换为 Kin 跟随玩家或直接入背包（隐藏物理体）；堆叠表现为视觉堆叠 + 少量碰撞（同类型可叠 5-10 个）。
5. **投喂链路**：饲料 Dyn 落地静止 → 动物 Sensor 检测到附近饲料 → 触发 eat 动画与饱食度。**性能注意**：避免饲料无限堆积不清理，投喂后 60s 未进食自动消失。
6. **性能**：静态碰撞体尽量合并（大地形 1 个 heightfield/trimesh；建筑/围栏批量合并）；同屏动态刚体上限建议 ≤ 60（动物 + 掉落物）；大量作物（InstancedMesh）不建物理体，用 Sensor 或命中判定替代。
7. **玩家角色**：胶囊体（半径≈0.35m，高≈1.7m）Dyn，质量≈80kg，地面摩擦适中；防止穿过围栏/建筑。

## 7. 动画需求总则（供 art-director）

1. **动画命名约定**（统一，供状态机/代码引用）：
   - 动物通用：`idle` / `walk` / `eat` / `hurt`；按需：`run`、`sleep`、`peck`、`swim`、`hop`、`sit`、`bark`。
   - 玩家：`idle` / `walk` / `run` / `swing_hoe` / `swing_scythe` / `swing_axe` / `water` / `cast_rod` / `reel_rod` / `pickup` / `sleep`。
   - 建筑/环境：默认无骨骼动画；动效走 Shader（水面、风摆）或粒子（烟雾、水滴）。
2. **动物状态机（建议）**：`Idle ⇄ Walk`；`Idle/Walk → Eat`（投喂后，播放 2-3s）→ `Idle`；受击/被撞 → `Hurt`（0.5s）→ `Idle`。每状态循环动画需**无缝循环**。
3. **骨骼复用策略**（控制成本）：
   - 4 足大型骨架：牛 / 猪 / 羊 / 马 / 羊驼 / 狗（同骨架换皮 + 缩放）。
   - 2 足小型骨架：鸡 / 鸭（换皮 + 嘴/翅差异）。
   - 4 足小型骨架：兔 / 猫（换皮 + 耳/尾差异）。
   - 鱼：程序化摆动（正弦），不建骨骼。
4. **动画来源**：优先 CC0 动画库（如 Mixamo 类卡通动作）重定向；动物动作以"卡通夸张"为准（Stylized 风格），避免写实走姿。
5. **LOD 与性能**：LOD0 面数建议（参考）：动物 1.5k-4k tris、建筑 5k-8k tris、植物 0.3k-0.8k tris、道具 0.1k-0.5k tris、环境 0.1k-1k tris；LOD1 为 50%-60%。最终以工程性能预算为准。

## 8. 生产顺序建议（供 team-lead 排期）

> 依据"先环境地基 → 再闭环功能 → 后丰富品种"的依赖逻辑。

| 里程碑 | 内容 | 依赖说明 |
|---|---|---|
| **M1（P0 首批，第一周）** | ① 地形/水面（ENV-001/004）→ ② 工具（锄/壶/镰/竿）→ ③ 作物+耕地（小麦/胡萝卜/地块）→ ④ 动物+畜舍（鸡/牛 + 鸡舍/牛棚/围栏）→ ⑤ 鱼（鲤鱼/鲈鱼 + 鱼塘）→ ⑥ 闭环件（农舍/出货箱/饲料/篮/蛋/奶） | 每步都是上一步的可玩出口：地形→能锄地→能种→能喂→能钓→能卖 |
| **M2（P1 第二波，第二周起）** | 品种扩展：羊/猪/鸭、6 种新作物、3 种果树、3 种新鱼、谷仓/水井、斧头、种子袋/羊毛/鱼篓、草丛/花丛/路径 | 建立在 M1 系统之上，纯加量 |
| **M3（P2 扩展，后续）** | 温室/马厩、马/兔/羊驼/猫/狗、高级作物/果树/花、肥料/蜂蜜/金币、山丘地形 | 长线内容，按留存数据取舍 |

**美术与工程建议并行**：M1 中地形与工具可最先开工（无动画依赖）；动物骨骼与动画资产开工最早（CC0 采购/重定向耗时最长），确保 M1 后期动物准时到位。
